# Image Gallery

An interactive image gallery built using HTML, CSS and JavaScript as part of my Frontend Development Internship at CodeAlpha.

The project allows users to browse images through a responsive gallery layout with smooth transitions and interactive navigation.

## Features

- Responsive image gallery layout
- Next and previous image navigation
- Lightbox view for images
- Hover effects and smooth transitions
- Interactive image browsing

## Technologies Used

- HTML
- CSS
- JavaScript
