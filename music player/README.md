# Music Player

A simple music player built using HTML, CSS and JavaScript as part of my Frontend Development Internship at CodeAlpha.

The project allows users to play and control music through an interactive interface.

## Features

- Play and pause music
- Next and previous track controls
- Display song title and artist
- Music progress bar
- Volume control
- Interactive music player interface

## Technologies Used

- HTML
- CSS
- JavaScript
