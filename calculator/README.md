# Calculator

A basic calculator built using HTML, CSS and JavaScript as part of my Frontend Development Internship at CodeAlpha.

The project allows users to perform basic mathematical calculations through a simple and interactive interface.

## Features

- Addition, subtraction, multiplication and division
- Clear button to reset the display
- Interactive calculator buttons
- Responsive user interface

## Technologies Used

- HTML
- CSS
- JavaScript
